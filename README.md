# Clean Aura – Fullstack Web Application & Cloud Infrastructure

A modern, high-performance web platform built with React, Vite, TypeScript, and Supabase, integrated with edge security and telemetry monitoring.

## 🚀 Key Features
* **Fullstack Integration:** Powered by React/Vite on the frontend and Supabase for database management and authentication.
* **Edge Security & WAF:** Hardened via Cloudflare WAF, enforced SSL/TLS, and custom rate-limiting rules.
* **Modern Build Stack:** Developed using Bun runtime and Vite for ultra-fast builds and module bundling.
* **Real-time Telemetry:** Edge-level logging and security tracking for incoming requests and threat detection.

## 🛠️ Tech Stack
* **Frontend:** React, TypeScript, Vite, Tailwind CSS
* **Backend & Database:** Supabase (Database, Auth)
* **Runtime & Package Manager:** Bun
* **Cloud & Security:** Cloudflare (WAF, DNS, Edge Analytics)
